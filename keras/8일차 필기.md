# 8일차 필기

## 1. 모델의 종류 (회귀 vs 분류)
* 모델은 크게 **회귀(Regression)**와 **분류(Classification)** 2종류로 나뉩니다.
* 자연어 처리는 다소 예외적인 부분이 있지만, 연속적인 값을 예측할 때는 회귀에 가깝습니다.
* **이진 분류**: `0`과 `1` (또는 True/False) 중 하나를 찾는 문제 (예: 합격/불합격)
* **다중 분류**: 여러 개 중 하나를 찾는 문제 (예: 가위/바위/보)

## 2. 회귀와 분류의 특징
* **회귀 (Regression)**
  * 출력층 활성화 함수 (Activation): `linear` (디폴트값)
  * 손실 함수 (Loss): `mse`, `mae`, `rmse` 등
* **분류 (Classification)**
  * 출력층 활성화 함수 (Activation): 
    * 이진 분류: `sigmoid` (수식: `1 / (1 + e^-z)`)
      * `wx + b`가 `0`이면 예측값 `y`는 `0.5`가 됩니다.
      * 계산 결과가 음수면 `0.5` 미만, 양수면 `0.5` 초과 값을 가집니다.
  * 손실 함수 (Loss): 
    * 이진 분류: `binary_crossentropy`
  * **참고**: `Logistic Regression`은 이름에 Regression이 들어가지만 **분류** 모델입니다. (나머지 Regression은 대부분 회귀)

* **Sigmoid 함수의 특징**
  * 결과값은 절대 `0`이나 `1`이 아니며, **`0` 초과 `1` 미만**의 실수입니다.
  * 따라서 이진 분류에서는 이 결과값을 **반올림(`np.round`)**하여 최종 판단(0 또는 1)을 합니다.
  * 예측값에 대한 반올림 처리는 **회귀에서는 하지 않으며**, 분류 모델에서 최종 클래스를 결정하거나 평가지표(accuracy 등)를 판단할 때 사용합니다.

* **데이터 확인 팁 (`np.unique` 활용)**
  * `0`, `1`만 보이면 이진 분류
  * `0`, `1`, `2` 등 3개 이상의 클래스가 보이면 다중 분류
  * `0.7` 같은 연속적인 실수가 나오면 회귀
  * 분명히 분류 문제라고 했는데 뜬금없는 실수가 나오면 데이터가 오염된 것입니다.

## 3. 총정리

1. **회귀 (Regression)**
   * `input_dim`: 그대로 사용
   * 출력층 `activation`: `linear` (또는 생략 가능)
   * 출력층 노드 개수: 예측하려는 값의 개수 (보통 1개)
   * `loss`: `mse`, `mae` 등
   * `predict`: 예측값을 그대로 사용 (별도 처리 불필요)

2. **분류 - 이진 분류 (Binary Classification)**
   * 출력층 `activation`: `sigmoid`
   * 출력층 노드 개수: 1개
   * `loss`: `binary_crossentropy`
   * `predict`: 예측 후 `np.round()`를 사용하여 `0` 또는 `1`로 반올림

3. **분류 - 다중 분류 (Multi-class Classification)**
   * **원-핫 인코딩 (One-Hot Encoding)** 필수 적용
   * 출력층 `activation`: `softmax`
   * 출력층 노드 개수: 정답 `y`의 클래스 개수만큼
   * `loss`: `categorical_crossentropy`
   * `predict`: 예측 후 `np.argmax()`를 사용하여 가장 확률이 높은 클래스의 인덱스를 추출
