# Scaler 정리

## 1. Scaling을 사용하는 이유

신경망의 한 뉴런은 기본적으로 다음과 같이 계산한다.

```text
h1 = w1x1 + w2x2 + w3x3 + b
```

여기서 예를 들어

```text
x1 = 키: 180
x2 = 몸무게: 60
x3 = 연봉: 1,000,000,000
```

이라고 생각해보자.

초기 가중치 `w1`, `w2`, `w3`는 일반적으로 작은 랜덤값으로 초기화된다.

예를 들어 세 가중치가 모두 `0.1`이라고 가정하면,

```text
h1 = 0.1 × 180
   + 0.1 × 60
   + 0.1 × 1,000,000,000
   + b
```

각 항은 다음과 같다.

```text
키      : 18
몸무게  : 6
연봉    : 100,000,000
```

연봉이라는 feature의 값의 크기가 압도적으로 크기 때문에 초기 학습에서는 키와 몸무게의 영향이 상대적으로 매우 작아질 수 있다.

즉, feature마다 단위와 값의 범위가 지나치게 다르면 feature별 Gradient 크기도 크게 달라질 수 있고, 학습이 비효율적이거나 불안정해질 수 있다.

따라서 Scaling을 사용하여 각 feature의 숫자 범위를 비슷하게 만들어준다.

> Scaling의 핵심 목적은 모든 feature를 똑같이 중요하게 만드는 것이 아니라,  
> **숫자의 단위나 크기 차이 때문에 특정 feature가 학습 과정에서 과도한 영향을 가지는 문제를 줄이는 것**이다.

## 2. MinMaxScaler

MinMaxScaler의 기본 설정은 **fit한 데이터의 최솟값을 0, 최댓값을 1로 변환**한다.

공식은 다음과 같다.

```text
X_scaled = (X - X_min) / (X_max - X_min)
```

예를 들어 한 feature에

```text
100, 200, 300
```

이 있다면,

```text
100 → 0.0
200 → 0.5
300 → 1.0
```

이 된다.

즉,

```text
최솟값 → 0
최댓값 → 1
```

이 되며 나머지 데이터는 그 사이의 상대적인 위치에 들어간다.

### 특징

- fit한 데이터의 범위를 기본적으로 `0 ~ 1`로 맞춘다.
- 데이터의 최소값과 최대값을 기준으로 상대적인 위치를 표현한다.
- 이상치가 존재하면 Min/Max 자체가 크게 변할 수 있으므로 이상치에 민감하다.
- Min-Max Scaling은 흔히 정규화(Normalization)의 한 방식이라고 부르기도 한다.

### 중요한 주의점

MinMaxScaler를 사용한다고 해서 **validation/test 데이터까지 항상 0~1에 들어가는 것은 아니다.**

예를 들어 train 데이터의 범위가

```text
100 ~ 300
```

이라면 Scaler는 다음 기준을 학습한다.

```text
X_scaled = (X - 100) / (300 - 100)
```

그런데 test 데이터에 `400`이 들어오면,

```text
(400 - 100) / 200
= 1.5
```

가 된다.

따라서 정확하게는,

> MinMaxScaler는 **fit에 사용된 데이터의 최솟값과 최댓값을 0과 1에 대응**시킨다.

라고 이해하는 것이 좋다.

## 3. StandardScaler

StandardScaler는 데이터를

```text
평균 = 0
표준편차 = 1
```

이 되도록 변환한다.

공식은 다음과 같다.

```text
z = (x - μ) / σ
```

여기서

```text
x = 현재 데이터
μ = 해당 feature의 평균
σ = 해당 feature의 표준편차
```

이다.

예를 들어 평균이 `100`, 표준편차가 `20`인 데이터에서

```text
x = 120
```

이라면,

```text
(120 - 100) / 20
= 1
```

이 된다.

즉 `1`이라는 값은 단순히 숫자 1이라는 의미가 아니라,

> **평균보다 표준편차 1개만큼 위에 있는 값**

이라는 의미이다.

반대로

```text
z = -2
```

이면,

> 평균보다 표준편차 2개만큼 아래에 있는 값

이라는 뜻이다.

---

## 4. StandardScaler 공식에서 분자와 분모의 의미

### 4-1. 분자: `x - μ`

```text
x - μ
```

는 현재 값이 평균에서 어느 방향으로 얼마나 떨어져 있는지를 나타낸다.

엄밀하게는 단순한 거리(distance)라기보다 **부호가 있는 편차(deviation)**이다.

예를 들어,

```text
x = 80
평균 = 100
```

이면,

```text
x - 평균 = -20
```

이다.

음수라는 것은 평균보다 아래쪽에 있다는 뜻이다.

또한 모든 데이터에 대해

```text
Σ(x - 평균) = 0
```

이 된다.

즉 평균을 기준으로 위쪽 편차와 아래쪽 편차를 모두 더하면 서로 상쇄된다.

### 4-2. 분모: `σ`

```text
σ
```

는 데이터들이 평균 주변에서 전반적으로 얼마나 퍼져 있는지를 나타내는 표준편차이다.

따라서

```text
(x - μ) / σ
```

는

> 현재 데이터가 평균에서 **표준편차 몇 개만큼 떨어져 있는가?**

를 의미한다.

### 주의

z-score가 크다고 해서 무조건 이상치라고 단정할 수는 없다.

예를 들어

```text
z = 3
```

이면 평균에서 표준편차 3개만큼 떨어져 있다는 의미지만, 실제로 얼마나 희귀한 값인지는 데이터의 분포에 따라 달라진다.

특히 데이터가 정규분포와 크게 다르면 z-score만으로 이상치 여부를 단정하기 어렵다.

## 5. MinMaxScaler와 StandardScaler의 직관적인 차이

### MinMaxScaler

데이터가 최솟값과 최댓값 사이에서 어디에 위치하는지를 표현한다.

예를 들어,

```text
0.0 → fit 데이터에서 가장 작은 값
0.5 → 최소와 최대 사이의 중간
1.0 → fit 데이터에서 가장 큰 값
```

즉,

> **전체 범위 안에서 현재 값이 어디에 있는가?**

라는 관점이다.

### StandardScaler

현재 데이터가 평균에서 얼마나 떨어져 있는지를 표현한다.

```text
0   → 평균
+1  → 평균보다 표준편차 1개 위
-1  → 평균보다 표준편차 1개 아래
+2  → 평균보다 표준편차 2개 위
```

즉,

> **평균을 기준으로 현재 값이 어느 방향으로 얼마나 떨어져 있는가?**

라는 관점이다.

정리하면,

```text
MinMaxScaler
→ 전체 범위 내 위치

StandardScaler
→ 평균과 표준편차를 기준으로 한 상대적 위치
```

라고 생각할 수 있다.

## 6. MaxAbsScaler

MaxAbsScaler는 각 feature를 **그 feature의 최대 절댓값**으로 나눈다.

공식은 다음과 같다.

```text
X_scaled = X / max(|X|)
```

예를 들어 한 feature에 다음 값이 있다고 해보자.

```text
-50, 0, 100
```

각 값의 절댓값은

```text
|-50| = 50
|0|   = 0
|100| = 100
```

이므로 최대 절댓값은

```text
max(|X|) = 100
```

이다.

따라서 모든 값을 100으로 나눈다.

```text
-50 → -50 / 100 = -0.5
0   →   0 / 100 =  0
100 → 100 / 100 =  1.0
```

결과는

```text
[-0.5, 0, 1.0]
```

이 된다.

### 중요한 점

MaxAbsScaler가 항상

```text
최솟값 → -1
최댓값 → +1
```

로 만드는 것은 아니다.

MaxAbsScaler는 **절댓값이 가장 큰 값만 ±1 중 하나가 되도록 만든다.**

위 데이터에서는

```text
|-50| = 50
|100| = 100
```

이므로 `100`이 최대 절댓값을 가진다.

따라서

```text
100 → 1.0
-50 → -0.5
```

가 된다.

반대로 데이터가

```text
-100, 0, 50
```

이라면,

```text
-100 → -1.0
0    →  0
50   →  0.5
```

가 된다.

### 특징

- 최대 절댓값이 `1`이 되도록 Scaling한다.
- `0`은 그대로 `0`으로 유지된다.
- 데이터의 양수/음수 부호를 유지한다.
- 평균이나 중앙값을 빼지 않으므로 데이터의 중심을 이동시키지 않는다.
- `0`이 많은 sparse 데이터에서도 0을 그대로 유지할 수 있다는 장점이 있다.
- 최대 절댓값 자체를 기준으로 사용하기 때문에 큰 이상치에 민감하다.

---

## 7. RobustScaler

RobustScaler는 이상치(Outlier)의 영향을 줄이기 위해 사용하는 Scaling 방법이다.

StandardScaler는

```text
평균
표준편차
```

를 사용한다.

문제는 매우 큰 이상치 하나가 존재하면 평균과 표준편차 자체가 크게 변할 수 있다는 것이다.

반면 RobustScaler는

```text
중앙값(Median)
IQR(Interquartile Range)
```

을 사용한다.

기본적인 공식은 다음과 같다.

```text
X_scaled = (X - Median) / IQR
```

IQR은

```text
IQR = Q3 - Q1
```

이다.

여기서

```text
Q1 = 25% 지점
Q3 = 75% 지점
```

이다.

### 왜 `(X - Median) / IQR`인가?

이 공식은 크게 두 단계로 이해하면 쉽다.

#### 1단계: `X - Median`

먼저 모든 값에서 중앙값(Median)을 뺀다.

```text
X - Median
```

이렇게 하면 중앙값이 `0`이 된다.

즉,

```text
Median → 0
```

이 된다.

StandardScaler에서

```text
X - 평균
```

을 하여 평균을 `0`으로 옮기는 것과 비슷한 역할이다.

다만 평균은 극단적인 값의 영향을 많이 받지만, 중앙값은 극단적인 값 몇 개가 존재해도 상대적으로 잘 움직이지 않는다.

예를 들어,

```text
1, 2, 3, 4, 1000
```

이라는 데이터가 있다면 중앙값은 `3`이다.

`1000`이라는 매우 큰 값이 존재해도 중앙값은 여전히 데이터의 가운데 위치를 잘 나타낸다.

따라서 RobustScaler는 데이터의 중심을 잡을 때 평균 대신 중앙값을 사용한다.

---

#### 2단계: `/ IQR`

중앙값을 뺀 것만으로는 feature마다 데이터의 퍼진 정도가 여전히 다를 수 있다.

그래서

```text
IQR = Q3 - Q1
```

로 나눈다.

IQR은 데이터의 가운데 50%가 얼마나 넓게 퍼져 있는지를 나타낸다.

즉,

```text
Q1 -------- Median -------- Q3
       가운데 50% 데이터
```

의 폭이 바로 IQR이다.

예를 들어,

```text
Q1 = 20
Q3 = 60
```

이라면

```text
IQR = 60 - 20
    = 40
```

이다.

이때 모든 값을 40으로 나누면 데이터의 대표적인 퍼짐 정도가 일정한 크기로 맞춰진다.

더 정확히 보면 Scaling 후 Q1과 Q3의 차이는

```text
Q3_scaled - Q1_scaled

= (Q3 - Median) / IQR
  - (Q1 - Median) / IQR

= (Q3 - Q1) / IQR

= IQR / IQR

= 1
```

이 된다.

즉 RobustScaler는

```text
중앙값 → 0
Q1 ~ Q3 사이의 폭 → 1
```

이 되도록 데이터의 중심과 대표적인 퍼짐 정도를 맞추는 방식이라고 볼 수 있다.

---

### 왜 평균과 표준편차 대신 Median과 IQR을 사용할까?

StandardScaler는

```text
(X - 평균) / 표준편차
```

를 사용한다.

하지만 평균과 표준편차는 극단적인 값에 영향을 많이 받는다.

반면 RobustScaler는

```text
(X - 중앙값) / IQR
```

을 사용한다.

중앙값과 IQR은 데이터의 가운데 부분을 기준으로 계산하므로 극단적으로 크거나 작은 값 몇 개가 있어도 Scaling 기준이 상대적으로 덜 흔들린다.

즉,

```text
Median을 뺀다
→ 이상치에 덜 흔들리는 중심을 0으로 맞춘다.

IQR로 나눈다
→ 이상치에 덜 흔들리는 대표적인 데이터 폭을 기준으로 크기를 맞춘다.
```

라고 이해하면 된다.

### 중요한 점

RobustScaler가 이상치를 제거하는 것은 아니다.

이상치는 그대로 존재한다.

단지,

> **이상치 때문에 Scaling 기준 자체가 지나치게 왜곡되는 현상을 줄이는 것**

이다.

### 특징 비교

```text
StandardScaler
→ 평균 + 표준편차 사용
→ 이상치의 영향을 비교적 많이 받음

RobustScaler
→ 중앙값 + IQR 사용
→ 이상치의 영향을 비교적 적게 받음
```

## 8. Scaler 비교 정리

```text
MinMaxScaler
→ 최솟값과 최댓값 사용
→ fit 데이터의 범위를 기본적으로 0~1로 변환
→ 이상치에 민감

StandardScaler
→ 평균과 표준편차 사용
→ 평균 0, 표준편차 1
→ 이상치에 비교적 민감

MaxAbsScaler
→ 최대 절댓값 사용
→ 최대 절댓값을 1로 변환
→ 0과 부호 유지
→ 이상치에 민감

RobustScaler
→ 중앙값과 IQR 사용
→ 이상치의 영향을 비교적 적게 받음
```

## 9. 어떤 Scaler를 사용해야 할까?

Scaler마다 데이터의 변환 방식이 다르기 때문에 무조건 하나의 Scaler가 항상 가장 좋은 것은 아니다.

실제 머신러닝/딥러닝에서는 다음과 같은 Scaler를 각각 적용해보고,

```text
MinMaxScaler
StandardScaler
MaxAbsScaler
RobustScaler
```

Validation 성능이나 Cross Validation 성능을 비교하여 선택할 수 있다.

다만 단순히 Test 점수가 가장 높은 Scaler를 골라서는 안 된다.

Scaler나 모델의 선택 기준으로 Test 데이터까지 반복적으로 사용하면 Test 데이터에 간접적으로 맞춰지는 문제가 생긴다.

따라서 일반적으로는,

```text
Train
→ 모델 학습

Validation / Cross Validation
→ 모델과 Scaler 선택

Test
→ 최종 성능 확인
```

의 역할을 분리하는 것이 좋다.

## 10. Scaling을 사용할 때 중요한 원칙

데이터를 먼저

```text
train / validation / test
```

로 나눈 뒤,

Scaler는 **train 데이터로만 fit**해야 한다.

```python
scaler.fit(x_train)

x_train = scaler.transform(x_train)
x_val   = scaler.transform(x_val)
x_test  = scaler.transform(x_test)
```

또는,

```python
x_train = scaler.fit_transform(x_train)
x_val   = scaler.transform(x_val)
x_test  = scaler.transform(x_test)
```

처럼 사용한다.

전체 데이터로 `fit()`을 해버리면 Validation/Test 데이터의

```text
최솟값
최댓값
평균
표준편차
중앙값
IQR
```

등의 정보가 Train 과정에 간접적으로 들어가게 된다.

이를 **Data Leakage(데이터 누수)**라고 한다.

## 11. Cross Validation과 Scaling

Cross Validation을 사용할 때는 한 단계 더 주의해야 한다.

예를 들어 5-Fold Cross Validation이라면 각 Fold마다

```text
Fold 1의 Train 데이터 → scaler.fit()
Fold 1의 Validation    → scaler.transform()

Fold 2의 Train 데이터 → scaler.fit()
Fold 2의 Validation    → scaler.transform()

...

Fold 5의 Train 데이터 → scaler.fit()
Fold 5의 Validation    → scaler.transform()
```

처럼 해야 한다.

즉, Cross Validation을 하기 전에 전체 `x_train`에 먼저 scaler를 fit하면 Validation Fold의 통계 정보가 Train Fold에 들어갈 수 있다.

이것도 Data Leakage가 될 수 있다.

scikit-learn에서는 이런 실수를 막기 위해 `Pipeline`을 사용하는 것이 편하다.

```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import LogisticRegression

model = Pipeline([
    ('scaler', StandardScaler()),
    ('model', LogisticRegression())
])
```

이 상태에서 Cross Validation을 실행하면 각 Fold마다 Train 데이터에만 Scaler가 fit된다.

## 12. 모델의 최적 Weight와 Bias 저장하기

딥러닝 학습의 결과는 결국 학습된

```text
Weight
Bias
```

를 포함한 모델의 Parameter이다.

학습 과정에서 가장 좋은 Validation 성능을 가진 상태를 저장해두면 나중에 다시 사용할 수 있다.

예를 들어 Keras의 `EarlyStopping`에서는

```python
from tensorflow.keras.callbacks import EarlyStopping

es = EarlyStopping(
    monitor='val_loss',
    patience=20,
    restore_best_weights=True
)
```

처럼 사용할 수 있다.

`restore_best_weights=True`를 설정하면 학습 종료 시점의 가중치를 그대로 사용하는 것이 아니라,

> **학습 과정에서 monitor 값이 가장 좋았던 시점의 Weight와 Bias**

를 다시 불러온다.

`monitor='val_loss'`라면 가장 낮은 `val_loss`를 기록한 시점의 가중치로 돌아간다.

모델 전체를 파일로 저장할 수도 있다.

```python
model.save('model.keras')
```

불러올 때는,

```python
from tensorflow.keras.models import load_model

model = load_model('model.keras')
```

처럼 사용할 수 있다.

## 13. IQR을 이용한 이상치 탐지

RobustScaler를 이해하려면 IQR을 이용한 이상치 탐지도 같이 알아두면 좋다.

기본적인 기준은 다음과 같다.

```text
IQR = Q3 - Q1

하한 = Q1 - 1.5 × IQR
상한 = Q3 + 1.5 × IQR
```

일반적으로,

```text
X < 하한
```

또는,

```text
X > 상한
```

인 데이터를 이상치 후보로 판단한다.

하지만 IQR 범위를 벗어났다고 해서 무조건 데이터를 삭제하면 안 된다.

예를 들어 연봉 데이터에서 실제 고액 연봉자가 존재한다면 통계적으로 극단적인 값이더라도 현실적으로는 정상 데이터일 수 있다.

따라서,

> **통계적으로 이상치 후보인지 확인한 뒤, 실제 데이터의 의미까지 보고 제거 여부를 결정해야 한다.**

## 14. 이상치와 Scaling은 다른 문제이다

Scaling과 이상치 탐지는 서로 관련은 있지만 같은 작업은 아니다.

Scaling은 주로

```text
feature마다 숫자 범위가 다른 문제
```

를 해결한다.

반면 이상치 탐지는

```text
특정 데이터가 전체 데이터 분포에서 지나치게 벗어나 있는가?
```

를 판단하는 문제이다.

또한 이상치는 단순히 `X` 값이 지나치게 크거나 작은 경우만을 의미하지 않는다.

예를 들어 동일하거나 매우 비슷한 `X`에 대해 `y`가 다른 데이터들과 크게 다른 경우도

```text
잘못된 라벨
노이즈
특이 사례
```

등을 의심할 수 있다.

따라서,

```text
Scaling
→ X의 숫자 단위와 범위를 조정

Outlier Detection
→ 데이터 자체가 비정상적이거나 특이한지 탐색
```

으로 구분해서 생각하는 것이 좋다.

## 15. 최종 요약

```text
MinMaxScaler
= (X - Min) / (Max - Min)
→ 범위 기준

StandardScaler
= (X - 평균) / 표준편차
→ 평균으로부터 표준편차 몇 개 떨어졌는지

MaxAbsScaler
= X / 최대절댓값
→ 부호와 0을 유지하면서 최대 절댓값을 1로

RobustScaler
= (X - 중앙값) / IQR
→ 이상치의 영향을 덜 받도록 Scaling
```

그리고 가장 중요한 원칙은,

```text
1. 데이터를 먼저 Train / Validation / Test로 나눈다.
2. Scaler는 Train 데이터에만 fit한다.
3. Validation/Test에는 transform만 한다.
4. Cross Validation에서는 각 Fold의 Train 부분에만 fit한다.
5. Test 데이터는 최종 평가용으로 남겨둔다.
```

이다.
