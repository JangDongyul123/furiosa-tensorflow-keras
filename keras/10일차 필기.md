Scaler 정리
1. Min-Max Scaling을 사용하는 이유
신경망의 한 뉴런은 기본적으로 다음과 같이 계산한다.
```text
h1 = w1x1 + w2x2 + w3x3 + b
```
여기서
`x1` = 키: 180
`x2` = 몸무게: 60
`x3` = 연봉: 10억
이라고 생각해보자.
초기 가중치 `w1`, `w2`, `w3`는 일반적으로 작은 랜덤값으로 초기화된다.
예를 들어 세 가중치가 모두 `0.1`이라고 가정하면,
```text
h1 = 0.1 × 180
   + 0.1 × 60
   + 0.1 × 1,000,000,000
   + b
```
각 항은 다음과 같다.
```text
키      : 18
몸무게  : 6
연봉    : 100,000,000
```
연봉이라는 feature의 값의 크기가 압도적으로 크기 때문에  
초기 학습에서는 키와 몸무게의 영향이 상대적으로 매우 작아질 수 있다.
즉, feature마다 단위와 값의 범위가 지나치게 다르면 Gradient의 크기 또한 feature별로 크게 달라질 수 있고, 학습이 비효율적이거나 불안정해질 수 있다.
따라서 Scaling을 사용하여 각 feature의 숫자 범위를 비슷하게 만들어준다.
---
2. MinMaxScaler
MinMaxScaler는 각 컬럼의 최솟값을 `0`, 최댓값을 `1`로 변환한다.
공식은 다음과 같다.
```text
X_scaled = (X - X_min) / (X_max - X_min)
```
예를 들어 한 컬럼에
```text
100, 200, 300
```
이 있다면,
```text
100 → 0.0
200 → 0.5
300 → 1.0
```
이 된다.
즉,
```text
최솟값 → 0
최댓값 → 1
```
이 되며 나머지 데이터들은 그 사이의 상대적인 위치에 들어간다.
특징
데이터 범위를 일반적으로 `0 ~ 1`로 맞춘다.
데이터의 최소·최대 범위를 직관적으로 보존한다.
이상치가 있으면 Min/Max 자체가 크게 변하기 때문에 이상치에 민감하다.
MinMaxScaler는 보통 정규화(Normalization) 방식 중 하나로 본다.
---
3. StandardScaler
StandardScaler는 데이터를
```text
평균 = 0
표준편차 = 1
```
인 형태로 변환한다.
공식은 다음과 같다.
```text
z = (x - μ) / σ
```
여기서
```text
x = 현재 데이터
μ = 해당 feature의 평균
σ = 해당 feature의 표준편차
```
이다.
예를 들어 평균이 `100`, 표준편차가 `20`인 데이터에서
```text
x = 120
```
이라면
```text
(120 - 100) / 20
= 1
```
이 된다.
즉 `1`이라는 값은 단순히 숫자 1이라는 의미보다는,
> **평균보다 표준편차 1개만큼 위에 있는 값**
이라는 의미를 가진다.
반대로
```text
z = -2
```
이면
> 평균보다 표준편차 2개만큼 아래에 있는 값
이라는 의미이다.
---
StandardScaler 공식에서 분자와 분모의 의미
```text
x - μ
```
는 현재 데이터가 평균에서 얼마나 떨어져 있는지를 나타낸다.
즉 분자는
```text
현재 데이터와 평균 사이의 거리
```
이다.
단, 방향까지 표현하기 때문에 평균보다 작으면 음수가 된다.
그리고
```text
σ
```
는 데이터들이 평균 주변에서 전반적으로 얼마나 퍼져 있는지를 나타내는 표준편차이다.
따라서
```text
(x - μ) / σ
```
는
> 현재 데이터가 평균에서 표준편차 몇 개만큼 떨어져 있는가?
를 의미한다.
중요한 점
모든 데이터에 대해
```text
(x - 평균)
```
을 합하면 `0`이 된다.

---
4. MinMaxScaler와 StandardScaler의 직관적인 차이
MinMaxScaler
데이터가 최솟값과 최댓값 사이에서 어디에 위치하는지를 표현한다.
예를 들어
```text
0.0 → 이 feature에서 가장 작은 값
0.5 → 최소와 최대 사이 중간 정도
1.0 → 이 feature에서 가장 큰 값
```
즉,
> **전체 범위 안에서 현재 값이 어디에 있는가?**
라는 관점이다.
---
StandardScaler
현재 데이터가 평균에서 얼마나 떨어져 있는지를 표현한다.
```text
0   → 평균
+1  → 평균보다 표준편차 1개 위
-1  → 평균보다 표준편차 1개 아래
+2  → 평균보다 표준편차 2개 위
```
즉,
> **평균을 기준으로 현재 값이 얼마나 특이한 위치에 있는가?**
라는 관점이다.
따라서 직관적으로
```text
MinMaxScaler
→ 데이터의 전체 범위 내 위치

StandardScaler
→ 평균을 기준으로 한 상대적인 위치
```
라고 생각할 수 있다.
---
5. MaxAbsScaler
MaxAbsScaler는 각 feature의 최대 절댓값을 1로 만든다.
공식은 다음과 같다.
```text
X_scaled = X / max(|X|)
```
예를 들어
```text
-100, -50, 0, 50, 100
```
이 있다면,
```text
-100 → -1.0
-50  → -0.5
0    → 0
50   → 0.5
100  → 1.0
```
이 된다.
특징
최대 절댓값이 `1`이 된다.
`0`은 그대로 `0`이다.
데이터의 양수/음수 부호를 그대로 유지한다.
데이터의 중심을 이동시키지 않는다.
이상치에는 비교적 민감하다.
---
6. RobustScaler
RobustScaler는 이상치(Outlier)가 많은 데이터에서 유용한 Scaling 방법이다.
StandardScaler는
```text
평균
표준편차
```
를 사용한다.
문제는 매우 큰 이상치 하나가 존재하면 평균과 표준편차 자체가 크게 변할 수 있다는 것이다.
반면 RobustScaler는
```text
중앙값(Median)
IQR(Interquartile Range)
```
을 사용한다.
공식은 대략 다음과 같다.
```text
X_scaled = (X - Median) / IQR
```
IQR은
```text
IQR = Q3 - Q1
```
이다.
여기서
```text
Q1 = 25% 지점
Q3 = 75% 지점
```
이다.
따라서 극단적으로 크거나 작은 값 몇 개가 있어도 평균을 사용하는 StandardScaler보다 영향을 덜 받는다.
특징
```text
StandardScaler
→ 평균 + 표준편차 사용
→ 이상치의 영향을 비교적 많이 받음

RobustScaler
→ 중앙값 + IQR 사용
→ 이상치의 영향을 비교적 적게 받음
```
---
7. Scaler는 어떤 것을 사용해야 할까?
Scaler마다 데이터의 변환 방식이 다르기 때문에  
무조건 하나의 Scaler가 항상 가장 좋은 것은 아니다.
따라서 실제 머신러닝/딥러닝에서는
```text
MinMaxScaler
StandardScaler
MaxAbsScaler
RobustScaler
```
등을 각각 적용해보고 Validation 성능을 비교해서 선택할 수 있다.
다만 단순히 Test 점수가 높은 것을 골라서는 안 되고,
```text
Validation 성능
Cross Validation 성능
```
등을 기준으로 선택해야 한다.
Test 데이터는 최종 성능 확인을 위해 남겨두는 것이 좋다.
---
8. Scaling을 사용할 때 중요한 원칙
데이터를 먼저
```text
train / validation / test
```
로 나눈 뒤,
Scaler는 train 데이터로만 학습(fit) 해야 한다.
```python
scaler.fit(x_train)

x_train = scaler.transform(x_train)
x_val   = scaler.transform(x_val)
x_test  = scaler.transform(x_test)
```
또는
```python
x_train = scaler.fit_transform(x_train)
x_val   = scaler.transform(x_val)
x_test  = scaler.transform(x_test)
```
처럼 사용한다.
전체 데이터로 `fit()`을 해버리면 Validation/Test 데이터의 최소값, 최대값, 평균, 표준편차 등의 정보가 Train 과정에 간접적으로 들어가게 된다.
이를 **Data Leakage(데이터 누수)**라고 한다.
---
9. 모델의 최적 가중치와 Bias 저장하기
딥러닝 학습의 결과는 결국 학습된
```text
Weight
Bias
```
를 포함한 모델의 Parameter이다.
학습 과정에서 가장 좋은 Validation 성능을 가진 상태를 저장해두면 나중에 다시 사용할 수 있다.
예를 들어 Keras의 `EarlyStopping`에서는
```python
EarlyStopping(
    monitor='val_loss',
    patience=20,
    restore_best_weights=True
)
```
처럼 사용할 수 있다.
`restore_best_weights=True`를 설정하면 학습 종료 시점의 가중치가 아니라,
> **학습 과정에서 val_loss가 가장 좋았던 시점의 Weight와 Bias**
를 다시 불러온다.
모델 자체를 파일로 저장할 수도 있다.
```python
model.save('model.keras')
```
불러올 때는
```python
from tensorflow.keras.models import load_model

model = load_model('model.keras')
```
처럼 사용할 수 있다.

10. 추가로 공부할 내용
IQR을 이용한 이상치 탐지
RobustScaler를 이해하려면 IQR을 이용하여 이상치를 찾는 방법을 같이 공부하면 좋다.
기본적인 기준은 다음과 같다.
```text
IQR = Q3 - Q1

하한 = Q1 - 1.5 × IQR
상한 = Q3 + 1.5 × IQR
```
일반적으로
```text
X < 하한
또는
X > 상한
```
인 데이터를 이상치 후보로 판단한다.
단, IQR 범위를 벗어났다고 무조건 데이터를 삭제해야 하는 것은 아니다.
실제로 의미 있는 극단값일 수도 있기 때문에 데이터의 의미를 확인한 뒤 제거 여부를 결정해야 한다.
