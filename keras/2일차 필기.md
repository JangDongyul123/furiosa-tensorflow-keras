2교시

행렬 곱은 (앞 행렬의 가로 1줄) × (뒤 행렬의 세로 1줄)을 1:1로 짝지어 곱함

곱할 수 있는 전제 조건: 앞 행렬의 열 개수 == 뒤 행렬의 행 개수
- 가로로 옆으로 셀 때 채워지는 개수 = 열(Column) 개수
- 세로로 아래로 셀 때 채워지는 개수 = 행(Row) 개수
- 앞 행렬의 가로 길이라 함은 '열 개수'를 의미하고, 뒤 행렬의 세로 길이라 함은 '행 개수'를 의미함!
- 따라서 [앞의 가로 길이(열 개수)] == [뒤의 세로 길이(행 개수)] 가 같아야 짝이 맞아 곱할 수 있음!
  (예: (2 × 3) · (3 × 2) -> (2 × 2))

### 행렬 곱셈 예시 (Python/Numpy)
A = np.array([[1, 2, 3],
              [4, 5, 6]])  # shape: (2, 3)

B = np.array([[7, 8],
              [9, 10],
              [11, 12]]) # shape: (3, 2)

# 결과 C는 shape (2, 2)가 됨 (A의 행 개수 x B의 열 개수)
C = np.dot(A, B)  # 또는 C = A @ B
# C의 [1행 1열] 값: (1*7) + (2*9) + (3*11) = 58
# C의 [1행 2열] 값: (1*8) + (2*10) + (3*12) = 64
# C의 [2행 1열] 값: (4*7) + (5*9) + (6*11) = 139
# C의 [2행 2열] 값: (4*8) + (5*10) + (6*12) = 154
# 
# 최종 C 행렬의 값:
# [[ 58,  64],
#  [139, 154]]

[1, 2, 3]    ->SHAPE (3 , )

1 2 3
4 5 6    -> SHAPE (2,3)
