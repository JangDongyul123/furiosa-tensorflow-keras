# 13일차 필기

## 1. Dense와 CNN의 차이

Dense에서는 한 뉴런이 앞의 모든 입력을 바라본다.

```text
전체 입력
   ↓
x1w1 + x2w2 + ... + b
   ↓
뉴런
```

즉 Dense Layer에서는 하나의 뉴런이 이전 Layer의 모든 입력과 연결된다.

반면 CNN에서는 이미지 전체를 한 번에 보는 것이 아니라, 작은 영역을 보는 **Kernel(Filter)**을 사용한다.

```text
이미지의 3 × 3 영역
        ↓
3 × 3 Kernel
        ↓
같은 위치끼리 곱함
        ↓
전부 더함
        ↓
Bias를 더함
        ↓
출력값 하나
```

그리고 **같은 Kernel을 이미지의 다른 위치에서도 반복해서 사용한다.**

이것을 **Weight Sharing(가중치 공유)**이라고 한다.

```text
같은 Kernel
   ↓
위치 1에서 사용
   ↓
위치 2에서도 사용
   ↓
위치 3에서도 사용
   ↓
...
```

이 때문에 CNN은 Dense에 비해 이미지의 공간적 특징을 효율적으로 학습할 수 있다.

---

## 2. CNN도 결국 xw + b를 계산한다

Dense 뉴런은 다음과 같이 계산한다.

```text
y = x1w1 + x2w2 + x3w3 + ... + b
```

Conv2D도 본질적으로 같은 계산을 한다.

예를 들어 `3 × 3` Kernel이라면

```text
y
=
x1w1 + x2w2 + x3w3
+ x4w4 + x5w5 + x6w6
+ x7w7 + x8w8 + x9w9
+ b
```

이다.

즉 CNN 역시 본질적으로

```text
xw + b
```

를 계산한다.

차이는 Dense는 전체 입력을 보는 반면, CNN은 작은 영역을 보고 같은 Weight를 여러 위치에서 반복해서 사용한다는 점이다.

---

## 3. Flatten

Conv2D의 출력은 아직 이미지 형태의 다차원 데이터이다.

예를 들어 Conv2D의 출력이

```text
(None, 7, 7, 5)
```

라고 하자.

의미는 다음과 같다.

```text
None = Batch Size
7    = 세로
7    = 가로
5    = Channel
```

이 데이터를 Dense Layer에 연결하려면 보통 `Flatten()`을 이용해서 1차원으로 펼친다.

```python
model.add(Flatten())
```

계산하면

```text
7 × 7 × 5
= 245
```

이므로

```text
(None, 7, 7, 5)
        ↓
     Flatten
        ↓
(None, 245)
```

가 된다.

중요한 점은 `Flatten()`은 데이터를 학습하거나 값을 바꾸는 Layer가 아니라, **모양(shape)만 펼치는 Layer**라는 것이다.

```text
7 × 7 × 5
=
245개의 값

↓ Flatten

245
```

값의 개수 자체는 변하지 않는다.

---

## 4. MaxPooling2D

CNN에서는 Conv2D 뒤에 `MaxPooling2D`를 사용하기도 한다.

```python
MaxPooling2D(pool_size=(2, 2))
```

`pool_size=(2,2)`는 한 번에

```text
2 × 2
```

영역을 본다는 뜻이다.

예를 들어

```text
1  3
2  7
```

이라면 가장 큰 값 하나를 선택한다.

```text
max(1, 3, 2, 7)
=
7
```

따라서

```text
1  3
2  7

↓

7
```

이 된다.

즉 MaxPooling은

```text
Feature Map의 크기를 줄이면서
강하게 나타난 특징을 남기는 연산
```

이다.

---

## 5. Conv2D와 MaxPooling2D는 서로 다른 연산이다

`Conv2D`와 `MaxPooling2D`는 하나의 연산이 아니라 **서로 다른 Layer**이다.

```text
Conv2D
=
Convolution 연산
=
학습 가능한 Kernel을 사용해서 특징을 찾음
```

```text
MaxPooling2D
=
Max Pooling 연산
=
일정 영역에서 가장 큰 값만 선택
```

보통 다음처럼 연달아 사용한다.

```python
model.add(Conv2D(32, (3, 3), activation='relu'))
model.add(MaxPooling2D(pool_size=(2, 2)))
```

흐름은

```text
입력 이미지
   ↓
Conv2D
특징 추출
   ↓
Feature Map
   ↓
MaxPooling2D
특징 압축
```

이다.

---

## 6. MaxPooling2D는 Channel을 합치지 않는다

Conv2D에서는 입력 Channel이 여러 개라면 Filter 하나가 모든 입력 Channel을 함께 본다.

예를 들어 입력이

```text
32 × 32 × 3
```

이고 Kernel Size가

```text
3 × 3
```

이라면 Filter 하나의 실제 크기는

```text
3 × 3 × 3
```

이다.

즉 RGB 3개 Channel을 모두 계산한 뒤 더해서 **출력 Channel 하나**를 만든다.

```text
Channel 1 ─┐
Channel 2 ─┼─→ 합산 → 출력 Channel 1개
Channel 3 ─┘
```

반면 MaxPooling2D는 Channel을 합치지 않는다.

예를 들어 입력이

```text
4 × 4 × 3
```

이라면

```text
Channel 1 → 따로 MaxPooling
Channel 2 → 따로 MaxPooling
Channel 3 → 따로 MaxPooling
```

을 수행한다.

따라서

```text
4 × 4 × 3
     ↓
MaxPooling2D((2,2))
     ↓
2 × 2 × 3
```

처럼 **가로와 세로는 줄어들 수 있지만 Channel 수는 그대로 유지된다.**

---

## 7. MaxPooling2D에는 학습할 Weight가 없다

Conv2D의 Kernel에는 학습되는 Weight가 있다.

예를 들어

```text
w1 w2 w3
w4 w5 w6
w7 w8 w9
```

와 같은 Weight가 학습을 통해 바뀐다.

반면 MaxPooling은 단순히

```text
2 × 2 영역에서 가장 큰 값 하나 선택
```

이라는 규칙을 사용한다.

따라서 MaxPooling2D에는 학습할 Weight나 Bias가 없다.

```text
MaxPooling2D Parameter = 0
```

이다.

---

# 8. Stride

## Stride란?

Stride는 **Kernel 또는 Pooling 영역이 한 번 계산한 뒤 몇 칸 이동할지**를 의미한다.

쉽게 말하면

```text
Stride = 이동 보폭
```

이다.

Conv2D의 기본값은

```python
strides=(1, 1)
```

이다.

즉 가로로 1칸, 세로로 1칸씩 이동한다.

---

## 9. stride=1

1차원으로 단순하게 생각해보자.

입력이

```text
A B C D E
```

이고 Kernel Size가 `3`이라고 하자.

`stride=1`이면 한 칸씩 이동한다.

```text
[A B C]
  [B C D]
    [C D E]
```

즉 Kernel이 서로 겹치면서 이동한다.

이렇게 겹쳐서 보는 이유는 **특징이 어디에 걸쳐 있을지 모르기 때문**이다.

예를 들어 중요한 특징이

```text
C D
```

사이에 존재한다고 하자.

영역을 겹치지 않고 나누면

```text
[A B C] [D E F]
```

처럼 `C`와 `D`가 서로 다른 영역으로 나뉘어 하나의 Kernel이 둘을 동시에 보지 못할 수 있다.

하지만 `stride=1`이면

```text
[A B C]
  [B C D]
    [C D E]
```

처럼 `C`와 `D`를 함께 보는 구간이 생긴다.

따라서 특징을 더 촘촘하게 찾을 수 있다.

---

## 10. stride=2

`stride=2`이면 두 칸씩 이동한다.

```text
[A B C]
    [C D E]
```

즉 `stride=1`보다 계산 횟수가 줄어든다.

정리하면

```text
stride 작음
→ 더 촘촘하게 검사
→ 계산량 증가
→ 출력 Feature Map이 더 큼
```

```text
stride 큼
→ 더 듬성듬성 검사
→ 계산량 감소
→ 출력 Feature Map이 더 작음
```

단, 계산량이 많다고 항상 성능이 더 좋은 것은 아니다.

---

# 11. Padding

## Padding이 필요한 이유

Kernel을 이미지 위에서 이동시키다 보면 가장자리에서 문제가 생긴다.

예를 들어 입력이

```text
A B C D E
```

이고

```text
Kernel Size = 3
Stride = 1
```

이라면 Padding이 없을 때 Kernel은 다음처럼 움직인다.

```text
[A B C]
  [B C D]
    [C D E]
```

가운데에 있는 값들은 여러 번 Kernel에 포함되지만 가장자리의 `A`, `E`는 한 번만 포함된다.

각 값이 Kernel에 포함되는 횟수를 세면

```text
A = 1번
B = 2번
C = 3번
D = 2번
E = 1번
```

이다.

또한 `A`를 Kernel의 가운데에 놓고 싶어도

```text
? A B
```

처럼 왼쪽 데이터가 부족하다.

`E`도 마찬가지이다.

```text
D E ?
```

즉 가장자리까지 같은 방식으로 Kernel을 이동시키려면 이미지 바깥에 공간이 필요하다.

이때 사용하는 것이 **Padding**이다.

---

# 12. padding='valid'

```python
padding='valid'
```

는 이미지 바깥에 Padding을 추가하지 않는다.

쉽게 말하면

```text
padding='valid'
=
Padding 없음
```

이라고 생각하면 된다.

예를 들어

```text
Input = 5
Kernel = 3
Stride = 1
```

이면 출력 크기는

```text
5 - 3 + 1
=
3
```

이다.

따라서 2차원 이미지라면

```text
5 × 5
↓
3 × 3 Kernel
padding='valid'
stride=1
↓
3 × 3
```

이 된다.

---

# 13. padding='same'

`padding='same'`은 Kernel이 가장자리까지 이동할 수 있도록 입력 바깥에 값을 추가한다.

TensorFlow의 Conv2D에서는 일반적으로 필요한 위치에 `0`을 채운다고 생각하면 된다.

예를 들어

```text
A B C D E
```

가 있을 때 Kernel Size가 `3`이면 양쪽에 0을 추가해서

```text
0 A B C D E 0
```

처럼 만들 수 있다.

그러면 Kernel은

```text
[0 A B]
  [A B C]
    [B C D]
      [C D E]
        [D E 0]
```

처럼 이동할 수 있다.

이제 `A`와 `E`도 Kernel의 가운데 위치에 놓을 수 있다.

즉 Padding을 사용하는 이유 중 하나는 **가장자리 정보도 더 적극적으로 계산에 참여시키기 위해서**이다.

---

## 14. 왜 이름이 same인가?

`stride=1`일 때 `padding='same'`을 사용하면 입력과 출력의 **가로·세로 크기**가 같아진다.

예를 들어

```text
입력
5 × 5
```

에

```text
Kernel = 3 × 3
Stride = 1
Padding = same
```

을 사용하면

```text
출력
5 × 5
```

이 된다.

즉

```text
5 × 5
↓
Conv2D
padding='same'
stride=1
↓
5 × 5
```

이다.

그래서 `same`이라고 부른다.

다만 Channel 수까지 같다는 뜻은 아니다.

예를 들어

```python
Conv2D(
    filters=10,
    kernel_size=(3, 3),
    input_shape=(32, 32, 3),
    padding='same'
)
```

이라면

```text
입력
32 × 32 × 3

↓

Conv2D
filters=10
padding='same'
stride=1

↓

출력
32 × 32 × 10
```

이 된다.

여기서

```text
32 × 32
```

는 `padding='same'`으로 유지되고,

```text
10
```

은 Filter가 10개이기 때문에 출력 Channel이 10개가 된 것이다.

---

# 15. padding='same'과 stride의 관계

`padding='same'`이라고 해서 항상 출력의 가로·세로가 입력과 완전히 같은 것은 아니다.

`stride=1`이면

```text
32 × 32
↓
padding='same'
stride=1
↓
32 × 32
```

이다.

하지만 `stride=2`이면

```text
32 × 32
↓
padding='same'
stride=2
↓
16 × 16
```

처럼 줄어든다.

따라서 정확하게는

> `padding='same'`은 Stride를 고려하여 필요한 Padding을 추가하는 방식이다.

라고 이해하면 된다.

---

# 16. Stride와 Padding을 함께 이해하기

Kernel Size가 `3`이고 입력이 다음과 같다고 하자.

```text
A B C D E
```

### padding='valid', stride=1

```text
[A B C]
  [B C D]
    [C D E]
```

출력 개수:

```text
3
```

---

### padding='same', stride=1

```text
0 A B C D E 0

[0 A B]
  [A B C]
    [B C D]
      [C D E]
        [D E 0]
```

출력 개수:

```text
5
```

---

### padding='same', stride=2

두 칸씩 이동하므로

```text
[0 A B]
      [B C D]
            [D E 0]
```

처럼 계산 횟수가 줄어든다.

즉

```text
Padding
=
가장자리에서 Kernel이 계산할 수 있도록 바깥에 공간을 추가
```

```text
Stride
=
Kernel이 몇 칸씩 움직일지 결정
```

이다.

---

# 17. 출력 크기 공식

일반적인 출력 크기는 다음과 같이 계산할 수 있다.

```text
Output
=
floor(
    (Input + 2 × Padding - Kernel Size)
    / Stride
)
+ 1
```

가로와 세로에 각각 적용한다.

---

## padding='valid', stride=1

Padding이 없으므로

```text
Padding = 0
```

이다.

따라서

```text
Output
=
Input - Kernel Size + 1
```

이 된다.

예:

```text
Input = 10
Kernel = 3

10 - 3 + 1
=
8
```

---

# 18. Parameter 수

Conv2D의 Parameter 수는 다음과 같다.

```text
(
Kernel Height
× Kernel Width
× Input Channels
+ Bias 1개
)
× Filters
```

즉

```text
(kernel_height
× kernel_width
× input_channels
+ 1)
× filters
```

이다.

예를 들어

```python
Conv2D(
    filters=10,
    kernel_size=(3, 3),
    input_shape=(10, 10, 1)
)
```

이라면

```text
Kernel 하나의 Weight 수
=
3 × 3 × 1
=
9
```

Bias 1개를 더하면

```text
9 + 1
=
10
```

Filter가 10개이므로

```text
10 × 10
=
100
```

따라서

```text
Parameter = 100
```

이다.

# 19. 전체 흐름

CNN의 기본 흐름은 다음처럼 생각할 수 있다.

```text
입력 이미지
      ↓
Conv2D
Kernel을 이용하여 특징 추출
      ↓
Feature Map
      ↓
MaxPooling2D
강한 특징을 남기며 크기 축소
      ↓
Conv2D
더 복잡한 특징 추출
      ↓
Feature Map
      ↓
Flatten
1차원으로 펼침
      ↓
Dense
최종 판단
```

# 20. 핵심 정리

CNN 입력:

```text
(batch_size, height, width, channels)
```

---

Kernel:

```text
이미지의 작은 영역을 보는 학습 가능한 가중치
```

---

Convolution:

```text
① Kernel이 이미지의 작은 영역을 본다.
② 같은 위치끼리 곱한다.
③ 곱한 값을 모두 더한다.
④ Bias를 더한다.
⑤ 출력값 하나가 만들어진다.
⑥ Kernel을 이동한다.
⑦ 이미지 전체에서 반복한다.
⑧ 결과를 모아 Feature Map을 만든다.
```

---

Stride:

```text
Kernel이 한 번 계산한 뒤 몇 칸 이동할지 결정하는 값
```

```text
stride 작음
→ 촘촘하게 검사
→ 계산량 증가
→ 출력 크기 증가
```

```text
stride 큼
→ 듬성듬성 검사
→ 계산량 감소
→ 출력 크기 감소
```

---

Padding:

```text
Kernel이 이미지 가장자리에서도 계산할 수 있도록
입력 바깥에 공간을 추가하는 것
```

```text
padding='valid'
=
Padding 없음
```

```text
padding='same'
=
Stride를 고려하여 필요한 Padding을 추가
```

`stride=1`인 경우

```text
입력 가로·세로 크기
=
출력 가로·세로 크기
```

가 된다.

---

MaxPooling2D:

```text
일정 영역에서 가장 큰 값 하나를 선택하여
Feature Map의 가로·세로 크기를 줄이는 연산
```

```text
Conv2D
→ Channel을 함께 계산
→ Filter 수가 출력 Channel 수가 됨

MaxPooling2D
→ 각 Channel을 따로 계산
→ Channel 수 유지
```

---

Flatten:

```text
다차원 Feature Map을
Dense에 넣기 위해 1차원으로 펼치는 Layer
```

---

합성곱 수식:

```text
출력값
=
Σ(입력값 × Kernel Weight)
+ Bias
```

즉 CNN 역시 본질적으로

```text
xw + b
```

를 계산한다.

다만 **작은 영역마다 같은 Weight를 반복해서 사용한다는 점**이 Dense와 다르다.

## 한 줄 정리

> **CNN은 작은 Kernel을 이미지 위에서 이동시키며 특징을 찾고, Stride는 Kernel의 이동 간격을 결정하며, Padding은 가장자리에서도 Kernel이 계산할 수 있도록 입력 바깥을 채워주는 역할을 한다. MaxPooling은 추출된 특징 중 강한 값을 남기며 Feature Map의 크기를 줄이고, Flatten은 마지막에 Feature Map을 Dense가 사용할 수 있도록 1차원으로 펼친다.**
