# 7일차 필기: 훈련 시간 측정, 과적합 방지 및 이진 분류

## 1. 훈련 시간 측정 (`time` 모듈)
모델이 학습하는 데 걸리는 시간을 측정하여 리소스 소모 및 효율성을 판단할 수 있습니다.
```python
import time

start_time = time.time()  # 시작 시간 기록

model.fit(...)

end_time = time.time()    # 종료 시간 기록
print("걸린 시간: ", end_time - start_time)
```

---

## 2. 과적합 (Overfitting) 이해하기
과적합은 모델이 훈련 데이터(`x_train`)에만 과도하게 맞춰져서, 처음 보는 새로운 데이터(`x_test` 또는 검증 데이터)에 대한 예측력이 오히려 떨어지는 현상입니다.

* **확인 방법:** `matplotlib`을 이용해 `loss`와 `val_loss`의 변화를 선 그래프로 시각화합니다.
* **과적합 발생 지점 (U자 곡선):** 에포크(Epoch)가 진행될수록 훈련 `loss`는 계속 떨어지지만, 어느 순간부터 검증 `val_loss`가 떨어지기를 멈추고 다시 상승하기 시작합니다. 이 상승하는 시점부터 과적합이 발생한 것입니다.

```python
import matplotlib.pyplot as plt

plt.plot(hist.history['loss'], label='loss')
plt.plot(hist.history['val_loss'], label='val_loss')
plt.legend()
plt.show()
```

---

## 3. 조기 종료 (Early Stopping)
위에서 확인한 과적합을 방지하기 위해, `val_loss`가 더 이상 떨어지지 않고 올라가기 시작할 때 **알아서 훈련을 멈추게 하는 케라스 콜백(Callback) 함수**입니다.

```python
from tensorflow.keras.callbacks import EarlyStopping

es = EarlyStopping(
    monitor='val_loss',          # 관찰할 지표 (검증 손실)
    mode='min',                  # 관찰 지표가 최소가 될 때가 최적 (accuracy의 경우 max)
    patience=10,                 # 10 epoch 동안 성능 개선이 없으면 훈련 조기 종료
    restore_best_weights=True    # 조기 종료 시 가장 성능이 좋았던 시점의 가중치로 롤백
)

# 모델 훈련 시 callbacks 파라미터에 리스트 형태로 전달
model.fit(..., callbacks=[es])
```

## 4. 이진 분류 (Binary Classification)
결과값이 0 또는 1 (예: 양성/음성, 합격/불합격, 생존/사망) 두 가지 중 하나로 떨어지는 문제를 이진 분류라고 합니다.

### 4.1. 주요 세팅 (★ 필수 암기)
* **마지막 레이어 활성화 함수:** `activation='sigmoid'`
  * 딥러닝 망을 거친 출력값을 무조건 0.0과 1.0 사이의 확률값으로 변환해줍니다.
* **Loss 함수:** `loss='binary_crossentropy'`
  * 이진 분류에서는 성능 평가에 MSE를 쓰지 않고 크로스 엔트로피를 사용합니다.
* **평가 지표 (Metrics):** `metrics=['accuracy']`
  * 정확도를 추가로 출력하여, 0.95가 나오면 95%의 정답률을 의미함을 직관적으로 확인할 수 있습니다.

```python
# 모델의 마지막 층
model.add(Dense(1, activation='sigmoid'))

# 컴파일
model.compile(loss='binary_crossentropy', optimizer='adam', metrics=['accuracy'])
```

### 4.2. 데이터 비율 유지 (Stratify)
분류 문제에서는 정답 라벨(y)의 비율이 한쪽으로 치우쳐 있을 수 있습니다 (예: 0이 80%, 1이 20%).
`train_test_split`으로 데이터를 나눌 때, **훈련용과 시험용 데이터 모두 원본 데이터와 동일한 라벨 비율을 가지도록** `stratify=y` 옵션을 주어야 특정 라벨에 편향되는 것을 막을 수 있습니다.
```python
x_train, x_test, y_train, y_test = train_test_split(
    x, y, train_size=0.7, stratify=y
)
```

### 4.3. 예측값 정수 변환 (np.round)
마지막 레이어의 **`sigmoid` 함수를 통과해 나온 값은 무조건 0과 1 사이의 실수형 확률값**(예: 0.86, 0.12)이 됩니다. 
따라서 `model.predict()`가 반환하는 결과물도 이 `sigmoid`를 거친 실수형 값입니다. `accuracy_score`로 정확도를 매기려면 정답(y_test)과 동일한 0 또는 1의 정수 형태여야 하므로, **0.5를 기준으로 반올림하여 이진 정답으로 변환**해 주어야 합니다.
```python
import numpy as np
from sklearn.metrics import accuracy_score

y_pred = model.predict(x_test)
y_pred = np.round(y_pred) # 반올림 (0.5 이상은 1, 미만은 0)

acc = accuracy_score(y_test, y_pred)
```
