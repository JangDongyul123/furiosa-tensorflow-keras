# 14일차 필기: CNN 특성 추출 및 차원 변환 구조

## 1. Pooling(풀링) 기법

CNN에서는 `Conv2D`를 통해 입력 데이터에서 특징(Feature)을 추출합니다.

Conv2D를 통과한 결과를 **특성 맵(Feature Map)** 이라고 합니다.

Pooling은 이러한 특성 맵의 **공간적 크기(Height, Width)를 줄여 연산량을 감소시키고 특징을 요약하는 방법**입니다.

대표적으로 다음과 같은 방법이 있습니다.

* `MaxPooling2D`
* `AveragePooling2D`
* `GlobalAveragePooling2D`

---

## 1.1 MaxPooling2D

`MaxPooling2D`는 지정된 영역 안에서 **가장 큰 값(Max)** 하나를 선택하는 방식입니다.

예를 들어 다음과 같은 2×2 영역이 있다고 가정합니다.

```text
1  3
2  8
```

여기에 `MaxPooling2D(pool_size=(2, 2))`를 적용하면 가장 큰 값인 `8`만 남습니다.

```text
1  3
2  8

↓ MaxPooling

8
```

CNN에서는 값이 크다는 것이 해당 필터가 특정 특징에 강하게 반응했다는 의미일 수 있습니다.

따라서 MaxPooling은 한 영역에서 **가장 강하게 활성화된 특징을 대표값으로 남기는 방법**이라고 이해할 수 있습니다.

또한 특징이 주변 몇 칸 정도 이동하더라도 같은 영역 안에서 최대값으로 선택될 수 있기 때문에, 작은 위치 변화에 대해 어느 정도 덜 민감해지는 효과가 있습니다.

### `pool_size`

Pooling을 수행할 영역의 크기입니다.

```python
MaxPooling2D(pool_size=(2, 2))
```

이면 다음과 같이 2×2 영역에서 가장 큰 값 하나를 선택합니다.

```text
2 × 2 영역

a b
c d

↓ Max

max(a, b, c, d)
```

---

### `strides`

Pooling 영역이 이동하는 보폭입니다.

Keras의 `MaxPooling2D`에서는 `strides`를 따로 지정하지 않으면 기본적으로 `pool_size`와 동일한 값이 사용됩니다.

```python
MaxPooling2D(pool_size=(2, 2))
```

는 사실상 다음과 같습니다.

```python
MaxPooling2D(
    pool_size=(2, 2),
    strides=(2, 2)
)
```

즉 2×2 영역을 보고 가로와 세로 방향으로 각각 2칸씩 이동합니다.

따라서 영역이 일반적으로 겹치지 않습니다.

```python
from tensorflow.keras.layers import MaxPooling2D

model.add(
    Conv2D(
        64,
        (3, 3),
        activation='relu'
    )
)

model.add(
    MaxPooling2D(
        pool_size=(2, 2)
    )
)
```

예를 들어 입력 특성 맵이

```text
(N, 28, 28, 64)
```

이고

```python
MaxPooling2D(pool_size=(2, 2))
```

를 적용하면, `padding='valid'`이고 크기가 정확히 나누어지는 경우 대략

```text
(N, 14, 14, 64)
```

가 됩니다.

### 중요한 점

Pooling은 일반적으로 **Height와 Width만 감소시키고 채널 수는 변경하지 않습니다.**

```text
(N, 28, 28, 64)

       ↓ MaxPooling2D

(N, 14, 14, 64)
```

채널은 그대로 `64`입니다.

또한 MaxPooling에는 학습해야 할 가중치 `W`와 Bias `b`가 없습니다.

따라서

```text
Trainable Parameter = 0
```

입니다.

---

# 1.2 GlobalAveragePooling2D(GAP)

`GlobalAveragePooling2D`는 각 채널의 **전체 Height × Width 값의 평균**을 구해 채널 하나를 값 하나로 압축합니다.

예를 들어 입력이

```text
(N, 7, 7, 64)
```

라면 채널이 총 64개 존재합니다.

각 채널마다

```text
7 × 7 = 49개
```

의 값이 있으므로, 각각의 채널에서 49개의 평균을 구합니다.

```text
채널 1의 7×7 → 평균값 1개
채널 2의 7×7 → 평균값 1개
채널 3의 7×7 → 평균값 1개
...
채널 64의 7×7 → 평균값 1개
```

따라서

```text
(N, 7, 7, 64)

        ↓ GlobalAveragePooling2D

(N, 64)
```

가 됩니다.

즉

```text
Height
Width
```

차원은 사라지고

```text
Channel
```

정보만 남습니다.

---

## 예시

입력이 다음과 같다고 생각해 보겠습니다.

```text
(N, 5, 5, 4)
```

채널이 4개이므로 각 채널의 `5 × 5 = 25개` 값을 평균냅니다.

```text
채널 1 → 평균 1개
채널 2 → 평균 1개
채널 3 → 평균 1개
채널 4 → 평균 1개
```

결과는

```text
(N, 4)
```

입니다.

---

# 1.3 Flatten과 GlobalAveragePooling2D 비교

입력 특성 맵이 다음과 같다고 가정합니다.

```text
(N, 7, 7, 64)
```

## Flatten

```text
7 × 7 × 64
= 3136
```

이므로

```text
(N, 7, 7, 64)

      ↓ Flatten

(N, 3136)
```

가 됩니다.

## GlobalAveragePooling2D

각 채널마다 평균값 하나만 남기므로

```text
(N, 7, 7, 64)

      ↓ GAP

(N, 64)
```

가 됩니다.

| 특징                     | `Flatten`                    | `GlobalAveragePooling2D`  |
| ---------------------- | ---------------------------- | ------------------------- |
| 변환 방식                  | 모든 값을 한 줄로 펼침                | 각 채널의 H×W 평균 계산           |
| `(7,7,64)` 출력          | `3136`                       | `64`                      |
| 자체 Trainable Parameter | 없음                           | 없음                        |
| 위치 정보                  | 값의 순서는 유지하지만 2차원 공간 구조는 평탄화됨 | H/W 위치 정보는 평균 과정에서 거의 사라짐 |
| 다음 Dense 입력 크기         | 매우 커질 수 있음                   | 채널 수만 남아 작음               |
| 전체 모델 파라미터             | Dense와 연결하면 매우 커질 수 있음       | Dense 입력이 작아 파라미터 감소      |
| 과적합 위험                 | 상대적으로 커질 수 있음                | 파라미터 감소로 과적합 완화에 도움       |

중요한 점은 **Flatten 자체에도 파라미터가 없고 GAP 자체에도 파라미터가 없다는 것**입니다.

차이는 그 다음 Dense와 연결할 때 나타납니다.

예를 들어 다음과 같이 Dense 100개를 연결한다고 가정합니다.

### Flatten 사용

```text
3136 → Dense(100)
```

필요한 파라미터는

```text
(3136 + 1) × 100
= 313,700
```

개입니다.

### GAP 사용

```text
64 → Dense(100)
```

이면

```text
(64 + 1) × 100
= 6,500
```

개입니다.

따라서 GAP를 사용하면 **뒤쪽 Dense 층의 파라미터 수를 크게 줄일 수 있습니다.**

이 때문에 ResNet을 비롯한 많은 CNN 구조에서는 마지막 분류기로 넘어가기 전에 `Flatten` 대신 `GlobalAveragePooling2D` 또는 이와 유사한 Global Pooling을 사용합니다.

# 2. 모델 구조 간 데이터 차원 변환

딥러닝에서는 모델이 요구하는 입력 Shape에 맞게 데이터의 모양을 변경해야 할 때가 있습니다.

대표적으로 다음을 사용합니다.

```text
NumPy reshape()
Keras Flatten()
```

둘 다 데이터의 모양을 변경하지만 사용하는 위치가 다릅니다.

---

# 2.1 DNN 형태의 데이터를 CNN에 적용하기

집값, 당뇨병 데이터처럼 표 형태로 구성된 정형 데이터는 보통 다음과 같습니다.

```text
(샘플 수, 특성 수)
```

예를 들어 `load_diabetes()`의 데이터는

```text
(442, 10)
```

입니다.

즉 한 사람당 특성이 10개 존재합니다.

```text
sample 1 → feature 10개
sample 2 → feature 10개
sample 3 → feature 10개
...
```

하지만 `Conv2D`는 일반적으로 다음과 같은 4차원 입력을 사용합니다.

```text
(N, Height, Width, Channel)
```

따라서 10개의 Feature를 Conv2D에 넣기 위해 모양을 강제로 변환할 수 있습니다.

```text
10 = 5 × 2 × 1
```

이므로

```python
x_train = x_train.reshape(-1, 5, 2, 1)
x_val   = x_val.reshape(-1, 5, 2, 1)
x_test  = x_test.reshape(-1, 5, 2, 1)
```

로 바꿀 수 있습니다.

Shape은

```text
(N, 10)

    ↓ reshape

(N, 5, 2, 1)
```

이 됩니다.

모델에서는 다음과 같이 받을 수 있습니다.

```python
model.add(
    Conv2D(
        64,
        (2, 2),
        input_shape=(5, 2, 1)
    )
)
```

---

## reshape에서 중요한 점

`reshape()`는 데이터의 **원소 개수를 바꾸지 않습니다.**

예를 들어

```text
10개
```

의 값을

```text
5 × 2 × 1 = 10개
```

로 모양만 변경합니다.

```text
[a, b, c, d, e, f, g, h, i, j]

↓

[[a, b],
 [c, d],
 [e, f],
 [g, h],
 [i, j]]
```

값 자체가 새로 생기거나 사라지는 것은 아닙니다.

---

## 주의: Tabular 데이터를 CNN으로 바꾼다고 공간 구조가 생기는 것은 아니다

이 부분이 매우 중요합니다.

```text
(N, 10)

↓

(N, 5, 2, 1)
```

로 바꿨다고 해서 10개의 Feature가 실제 이미지처럼 공간적인 관계를 가지게 되는 것은 아닙니다.

이미지는 보통

```text
옆 픽셀
위 픽셀
아래 픽셀
```

끼리 강한 관계가 있습니다.

그래서 CNN이 주변 영역을 보는 것이 자연스럽습니다.

하지만 정형 데이터에서는

```text
feature 1
feature 2
feature 3
```

가 배열상 서로 옆에 있다고 해서 실제 의미까지 서로 가까운 것은 아닙니다.

따라서 정형 데이터에 Conv2D를 사용하는 것은 **가능하지만 반드시 성능이 좋아진다고 보장할 수는 없습니다.**

실험을 통해 확인해야 합니다.

---

# 2.2 CNN 형태의 데이터를 DNN에 적용하기

MNIST 같은 이미지 데이터는 다음과 같은 Shape을 가질 수 있습니다.

```text
(N, 28, 28, 1)
```

일반적인 DNN에서는 각 샘플을

```text
(N, Features)
```

형태로 만들어 Dense 층에 전달하는 경우가 많습니다.

28×28 흑백 이미지는

```text
28 × 28 × 1
= 784
```

개의 값을 가지므로

```text
(N, 28, 28, 1)

↓

(N, 784)
```

로 펼칠 수 있습니다.

이를 수행하는 대표적인 방법은 두 가지입니다.

---

# 방법 1. NumPy `reshape()` 사용

모델에 넣기 전에 데이터 자체의 Shape을 변경합니다.

```python
x_train = x_train.reshape(-1, 28 * 28 * 1)
x_test = x_test.reshape(-1, 28 * 28 * 1)
```

Shape은

```text
(N, 28, 28, 1)

↓

(N, 784)
```

가 됩니다.

이후 바로 Dense에 넣을 수 있습니다.

```python
model.add(
    Dense(
        128,
        input_dim=784,
        activation='relu'
    )
)
```

---

# 방법 2. Keras `Flatten()` 사용

원본 데이터는 그대로 유지하고 모델 내부에서 펼칩니다.

```python
model.add(
    Flatten(
        input_shape=(28, 28, 1)
    )
)

model.add(
    Dense(
        128,
        activation='relu'
    )
)
```

데이터 흐름은 다음과 같습니다.

```text
입력
(N, 28, 28, 1)

↓

Flatten

(N, 784)

↓

Dense(128)

(N, 128)
```

CNN에서는 보통 Conv2D 연산 결과를 Dense 층으로 넘길 때 이 방식을 자주 사용합니다.

```text
Conv2D
  ↓
Conv2D
  ↓
MaxPooling2D
  ↓
Flatten
  ↓
Dense
  ↓
Output
```

---

## 참고: Dense가 반드시 2차원 입력만 받는 것은 아니다

엄밀하게 말하면 Keras의 `Dense`는 반드시 `(N, Features)` 형태의 2차원 입력만 받을 수 있는 것은 아닙니다.

고차원 Tensor가 들어오면 **마지막 축에 Dense 연산을 적용**할 수도 있습니다.

다만 우리가 일반적인 DNN 구조에서 이미지 전체를 하나의 Feature Vector로 처리하려면

```text
(N, H, W, C)

↓

(N, H×W×C)
```

형태로 만든 뒤 Dense에 넣는 경우가 많습니다.

그래서 CNN 학습 과정에서는 흔히

```text
Conv2D → Flatten → Dense
```

또는

```text
Conv2D → GlobalAveragePooling2D → Dense
```

구조를 사용합니다.

---

# 2.3 reshape와 Flatten의 차이

둘 다 데이터를 펼치거나 모양을 변경할 수 있지만 사용하는 위치가 다릅니다.

## reshape

NumPy 배열 자체의 Shape을 직접 변경합니다.

```python
x_train = x_train.reshape(-1, 784)
```

모델에 입력되기 **전**에 데이터가 변경됩니다.

```text
Data

reshape()

↓

Model
```

---

## Flatten

Keras의 Layer입니다.

```python
model.add(Flatten())
```

모델 내부에서 데이터를 펼칩니다.

```text
Data

↓

Model

Conv2D
↓

Flatten
↓

Dense
```

### 핵심

```text
reshape
= 데이터 배열 자체의 Shape 변경

Flatten
= 모델 내부에서 펼치는 Layer
```

---

# 3. Conv2D의 파라미터 개수 계산

`Conv2D`에서 학습해야 하는 Parameter는 크게 두 종류입니다.

```text
Weight
Bias
```

Conv2D의 Parameter 공식은 다음과 같습니다.

```text
(커널 높이 × 커널 너비 × 입력 채널 수 + Bias 1개)
× 출력 필터 수
```

수식으로 쓰면

```text
(Kernel_H × Kernel_W × Input_Channel + 1)
× Filters
```

입니다.

여기서 `+1`은 **필터 하나당 Bias 하나**를 의미합니다.

---

# 3.1 첫 번째 Conv2D 계산

입력 Shape이 다음과 같다고 가정합니다.

```text
(N, 5, 2, 1)
```

모델은 다음과 같습니다.

```python
model.add(
    Conv2D(
        64,
        (2, 2),
        input_shape=(5, 2, 1)
    )
)
```

조건은 다음과 같습니다.

```text
Kernel = 2 × 2
Input Channel = 1
Filter 개수 = 64
```

필터 하나의 Weight 개수는

```text
2 × 2 × 1
= 4
```

입니다.

필터 하나당 Bias가 하나 있으므로

```text
4 + 1
= 5
```

입니다.

필터가 총 64개이므로

```text
5 × 64
= 320
```

따라서

```text
Param = 320
```

입니다.

---

# 3.2 두 번째 Conv2D 계산

첫 번째 Conv2D가 필터 64개를 사용했다면 출력 채널은 64개입니다.

즉 다음 Conv2D의 입력 채널도 64개입니다.

```python
model.add(
    Conv2D(
        64,
        (2, 2)
    )
)
```

조건은 다음과 같습니다.

```text
Kernel = 2 × 2
Input Channel = 64
Output Filter = 64
```

필터 하나가 가지는 Weight는

```text
2 × 2 × 64
= 256
```

개입니다.

Bias를 하나 추가하면

```text
256 + 1
= 257
```

입니다.

이런 필터가 64개 있으므로

```text
257 × 64
= 16,448
```

따라서

```text
Param = 16,448
```

입니다.

---

# 3.3 왜 입력 채널 수가 공식에 들어가는가?

Conv2D의 중요한 특징입니다.

입력이

```text
(H, W, 64)
```

라면 Conv2D의 필터 하나도 입력의 깊이를 전부 봐야 합니다.

예를 들어

```python
Conv2D(
    filters=32,
    kernel_size=(3, 3)
)
```

이고 입력 채널이 64라면 필터 하나의 실제 크기는

```text
3 × 3 × 64
```

입니다.

즉

```text
입력 채널 64개 모두를 한 번에 본다.
```

그리고 이러한 필터가 32개 존재하면 출력 채널은

```text
32
```

가 됩니다.

```text
입력
(H, W, 64)

↓

3×3×64 필터 × 32개

↓

출력
(H', W', 32)
```

따라서

```text
출력 채널 수
=
필터 개수
```

라고 이해하면 됩니다.

# 4. 전체 구조 정리

## MaxPooling2D

```text
(H, W, C)

↓

(H/2, W/2, C)
```

와 같이 공간 크기를 줄입니다.

* 특정 영역의 최대값 선택
* Height, Width 감소
* Channel 유지
* Trainable Parameter 없음
* 작은 위치 변화에 어느 정도 덜 민감해지는 효과

---

## GlobalAveragePooling2D

```text
(N, H, W, C)

↓

(N, C)
```

로 변환합니다.

각 채널별로

```text
H × W
```

개의 값의 평균을 계산합니다.

* 공간 차원 제거
* 채널별 대표값 하나 생성
* Trainable Parameter 없음
* 뒤쪽 Dense의 Parameter를 크게 줄일 수 있음
* 과적합 완화에 도움

---

## Flatten

```text
(N, H, W, C)

↓

(N, H × W × C)
```

로 변환합니다.

예:

```text
(N, 7, 7, 64)

↓

(N, 3136)
```

* 값 자체를 버리지는 않음
* 값의 순서는 유지
* 명시적인 H/W 구조는 사라짐
* Trainable Parameter 없음

---

## reshape

배열의 원소 수를 유지하면서 Shape을 직접 변경합니다.

```text
(N, 10)

↓

(N, 5, 2, 1)
```

또는

```text
(N, 28, 28, 1)

↓

(N, 784)
```

와 같이 사용할 수 있습니다.

---

## Conv2D Parameter 공식

```text
(Kernel_H × Kernel_W × Input_Channel + 1)
× Output_Filter
```

여기서

```text
+1
```

은 **필터 하나당 Bias 하나**입니다.

그리고

```text
이전 Conv2D의 Filter 개수
=
다음 Conv2D의 Input Channel 수
```

가 됩니다.

---

# 핵심 요약

```text
MaxPooling2D
→ 작은 영역에서 최대값 선택
→ H, W 감소
→ Channel 유지
→ Parameter 없음
```

```text
GlobalAveragePooling2D
→ 채널별 H×W 전체 평균
→ (N,H,W,C) → (N,C)
→ Parameter 없음
→ Dense 입력 크기를 크게 줄일 수 있음
```

```text
Flatten
→ 모든 값을 한 줄로 펼침
→ (N,H,W,C) → (N,H×W×C)
→ Parameter 없음
```

```text
reshape
→ 모델에 넣기 전 배열 자체의 Shape 변경
```

```text
Conv2D
→ 이전 Layer의 모든 입력 채널을 깊이 방향으로 함께 봄
→ Filter 개수 = 출력 Channel 개수
```

```text
Conv2D Params
=
(Kernel_H × Kernel_W × Input_Channel + 1)
× Output_Filter
```
