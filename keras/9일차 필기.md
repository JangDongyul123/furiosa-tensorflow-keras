# 오전 수업

## 1. 회귀 / 이진 분류 / 다중 분류 확인

문제의 정의를 이미 알고 있다면 회귀인지 분류인지 알 수 있다.

하지만 `y` 데이터만 주어진 상태에서 어떤 분류 문제인지 확인하려면 **정답 데이터의 클래스 종류와 개수**를 확인할 수 있다.

```python
print(np.unique(y, return_counts=True))
```

예:

```text
(array([0, 1, 2]), array([59, 71, 48]))
```

의미:

```text
클래스 0 : 59개
클래스 1 : 71개
클래스 2 : 48개
```

따라서 정답 클래스가

```text
0, 1, 2
```

총 3개 존재하므로 **3-class 다중 분류 문제**임을 확인할 수 있다.

### `np.unique()` 예시

```text
[0, 1]
→ 이진 분류일 가능성이 높음

[0, 1, 2]
→ 3-class 다중 분류일 가능성이 높음
```

단, **숫자의 종류만 보고 무조건 회귀/분류를 결정하면 안 된다.**

예를 들어

```text
1, 2, 3, 4, 5
```

가

* 서로 다른 5개의 카테고리를 의미한다면 → 분류
* 별점이나 점수처럼 숫자의 크기 자체가 의미가 있다면 → 회귀 또는 순서형 문제

일 수 있다.

결국 가장 중요한 것은 **정답 `y`가 무엇을 의미하는가**이다.

# 2. Softmax를 분석해보자

## 2-1. Softmax의 기본적인 직관

다중 분류에서는 출력층에 클래스 개수만큼 뉴런을 만든다.

예를 들어 클래스가 3개라면:

```python
Dense(3, activation='softmax')
```

출력층에서는 우선 각 클래스에 대한 **점수(logit)**가 계산된다.

예:

```text
[1, 2, 7]
```

이를 단순하게 생각하면 각각의 값을 전체 합으로 나누어

```text
1 + 2 + 7 = 10

[1/10, 2/10, 7/10]

= [0.1, 0.2, 0.7]
```

처럼 합이 1인 비율로 만들 수 있을 것 같다.

하지만 이것은 **Softmax를 이해하기 위한 단순한 직관일 뿐 실제 Softmax 계산법은 아니다.**

실제 Softmax는 각각의 값에 **지수 함수 `e^z`**를 적용한다.

---

# 3. 실제 Softmax 공식

Softmax의 공식은 다음과 같다.

$$
Softmax(z_i)
=
\frac{e^{z_i}}
{\sum_j e^{z_j}}
$$

쉽게 말하면:

```text
특정 클래스의 e^점수
--------------------------
모든 클래스의 e^점수 합
```

이다.

예를 들어:

```text
z = [1, 2, 7]
```

이라면

```text
[e¹, e², e⁷]
```

을 먼저 계산한 뒤 전체 합으로 나눈다.

결과는 대략:

```text
[0.0025, 0.0067, 0.9909]
```

가 된다.

즉:

```text
class 0 : 약 0.25%
class 1 : 약 0.67%
class 2 : 약 99.09%
```

이다.

그리고 항상:

```text
0.0025 + 0.0067 + 0.9909 ≈ 1
```

이 된다.

---

# 4. 왜 지수 함수 `e^z`를 사용하는가?

## 4-1. 모든 값을 양수로 만들 수 있다

출력층의 계산값인 logit은

$$
z = wx+b
$$

로 계산되므로 음수가 나올 수도 있다.

예:

```text
[-2.5, 1.2, 3.7]
```

그런데 확률은 음수가 될 수 없다.

지수 함수를 적용하면:

$$
e^z > 0
$$

이므로 어떤 실수도 **항상 양수**가 된다.

예:

$$
e^{-2.5} \approx 0.082
$$

여기서 주의할 점은:

> `e^z` 자체가 0~1 사이의 값이 되는 것은 아니다.

예를 들어:

$$
e^7 \approx 1096.63
$$

처럼 1보다 훨씬 큰 값도 나온다.

그 후 전체 `e^z`의 합으로 나누기 때문에 최종 Softmax 결과가

```text
0 < probability < 1
```

범위가 되는 것이다.

즉:

```text
logit
 ↓
e^z
 ↓
모두 양수가 됨
 ↓
전체 합으로 나눔
 ↓
0~1 사이의 확률
```

이다.

---

# 5. 지수 함수는 클래스 간 차이를 강조한다

지수 함수는 큰 값과 작은 값 사이의 차이를 크게 만든다.

예:

```text
[1, 2, 7]
```

단순 비율 계산:

```text
[0.1, 0.2, 0.7]
```

Softmax:

```text
[0.0025, 0.0067, 0.9909]
```

`7`이라는 가장 큰 값이 훨씬 강하게 부각된다.

따라서 Softmax는 **클래스 간 상대적인 점수 차이를 확률 분포로 표현한다.**

---

# 6. Softmax의 출력

예를 들어 클래스가 5개이고 출력층에서 다음과 같은 logit이 계산되었다고 하자.

```text
[1.3, 5.1, 2.2, 0.7, 1.1]
```

Softmax를 적용하면 대략:

```text
[0.020, 0.903, 0.050, 0.011, 0.017]
```

가 된다.

확률의 합:

```text
0.020
+ 0.903
+ 0.050
+ 0.011
+ 0.017
≈ 1.0
```

가장 높은 값은:

```text
index 1 → 0.903
```

이다.

따라서:

```python
np.argmax(pred)
```

을 사용하면 결과는:

```text
1
```

이다.

여기서 **결과 `1`은 확률값이 1이라는 뜻이 아니다.**

> 가장 큰 확률값이 존재하는 **인덱스 번호가 1번**이라는 뜻이다.

---

# 7. `np.argmax()`

`argmax`는 **가장 큰 값 자체를 반환하는 함수가 아니다.**

가장 큰 값이 존재하는 **위치(index)**를 반환한다.

예:

```python
pred = [0.02, 0.90, 0.05, 0.01, 0.02]

print(np.argmax(pred))
```

결과:

```text
1
```

왜냐하면:

```text
index       0     1     2     3     4
확률       .02   .90   .05   .01   .02
                  ↑
                최대값
```

이기 때문이다.

---

# 8. 같은 점수가 존재한다면?

예:

```text
softmax([2.0, 2.0, 0.1])
```

앞의 두 logit이 동일하다.

지수 변환 후에도:

```text
e² = e²
```

이므로 두 클래스의 확률도 같다.

Softmax 결과는 대략:

```text
[0.4652, 0.4652, 0.0696]
```

가 된다.

즉 모델 입장에서는:

```text
class 0 : 46.52%
class 1 : 46.52%
class 2 :  6.96%
```

처럼 class 0과 class 1을 거의 구분하지 못하는 상태이다.

이때:

```python
np.argmax([0.4652, 0.4652, 0.0696])
```

을 실행하면:

```text
0
```

이 반환된다.

NumPy의 `argmax()`는 동일한 최대값이 여러 개 존재하면 **가장 먼저 등장한 인덱스**를 반환하기 때문이다.

---

# 9. 다중 분류 출력층에서는 무엇을 계산하는가?

출력층 직전까지 신경망에서는 계속

$$
Wx+b
$$

형태의 계산을 수행한다.

다중 분류에서:

```python
Dense(3)
```

을 사용한다면 출력 뉴런 3개가 각각 하나의 값을 계산한다.

예:

```text
Dense(3)

      ↓

[1.3, 5.1, 2.2]
```

이 값들을 **logit**, 즉 각 클래스에 대한 점수라고 한다.

### 주의

이를 **"3개의 회귀 모델"이라고 표현하는 것은 정확하지 않다.**

계산 결과가 연속적인 실수라는 점에서는 회귀와 비슷해 보이지만, 최종 목적과 Loss가 다르다.

정확하게는:

> `Dense(3)`이 클래스 3개에 대한 **3개의 점수(logit)**를 계산한다.

라고 이해하는 것이 좋다.

# 10. 회귀와 다중 분류의 차이

## 회귀

마지막 Dense에서 계산한 연속적인 값을 그대로 예측값으로 사용한다.

```text
Wx+b
 ↓
예측값

152.7
```

---

## 다중 분류

마지막 Dense에서 클래스별 점수를 계산한다.

```text
Wx+b

↓

[1.3, 5.1, 2.2]

↓

Softmax

↓

[0.02, 0.93, 0.05]

↓

argmax

↓

1번 클래스
```

즉 둘 다 Dense 내부에서는 행렬 연산을 사용하지만, **분류와 회귀는 학습 목적과 출력 처리 방식이 서로 다르다.**

# 11. One-Hot Encoding과 Softmax

여기서 헷갈리기 쉬운 부분이 있다.

## One-Hot Encoding

One-Hot Encoding은 **정답 `y`를 표현하는 방법**이다.

예를 들어 클래스가:

```text
0
1
2
```

라면 One-Hot Encoding 후:

```text
0 → [1, 0, 0]
1 → [0, 1, 0]
2 → [0, 0, 1]
```

이 된다.

---

## Softmax

Softmax는 모델이 계산한 클래스별 점수를 **확률 분포**로 변환한다.

예:

```text
logit

[2.0, 1.0, 0.1]

↓

Softmax

[0.659, 0.242, 0.099]
```

따라서:

```text
One-Hot Encoding
→ 정답 y를 표현하는 방법

Softmax
→ 모델의 출력값을 확률 분포로 만드는 함수
```

이다.

Softmax가:

```text
[0.659, 0.242, 0.099]
```

를 자동으로:

```text
[1, 0, 0]
```

으로 만드는 것은 아니다.

최종 클래스가 필요하다면:

```python
np.argmax(pred)
```

을 사용한다.

---

# 12. One-Hot Encoding은 항상 필수인가?

다중 분류라고 해서 One-Hot Encoding이 반드시 필요한 것은 아니다.

### One-Hot Encoding한 경우

정답:

```text
[1, 0, 0]
[0, 1, 0]
[0, 0, 1]
```

Loss:

```python
loss='categorical_crossentropy'
```

---

### 정수 Label을 그대로 사용하는 경우

정답:

```text
0
1
2
```

Loss:

```python
loss='sparse_categorical_crossentropy'
```

따라서:

```text
One-Hot Encoding
→ categorical_crossentropy

정수 클래스 Label
→ sparse_categorical_crossentropy
```

로 기억하면 된다.

# 13. 모델보다 먼저 중요한 것은 데이터

좋은 모델 구조를 만드는 것도 중요하지만, 그 이전에 **데이터를 제대로 이해하고 전처리하는 것이 매우 중요하다.**

예를 들어 다음을 확인해야 한다.

```text
결측치
이상치
데이터 타입
Feature의 범위
Target의 분포
클래스 불균형
중복 데이터
Scaling 필요 여부
```

모델이 아무리 좋아도 입력 데이터가 잘못되어 있으면 좋은 결과를 만들기 어렵다.

> Garbage In, Garbage Out

즉 **잘못된 데이터를 넣으면 잘못된 결과가 나온다.**

# 15. `input_dim`과 `input_shape`

Dense 모델에서 입력 Feature가 4개라면:

```python
input_dim=4
```

와

```python
input_shape=(4,)
```

는 같은 입력 구조를 의미한다.

예:

```text
x.shape

(n, 4)
```

여기서 `n`은 데이터의 개수, 즉 **batch 축**이다.

모델의 `input_shape`에는 일반적으로 맨 앞의 데이터 개수 `n`을 제외한다.

따라서:

```text
데이터 Shape          input_shape

(n, 4)             → (4,)

(n, 100, 3)        → (100, 3)

(n, 100, 100, 3)   → (100, 100, 3)
```

즉:

> 전체 데이터 Shape에서 **맨 앞의 batch 차원을 제외한 나머지 Shape**가 모델의 `input_shape`가 된다.

# 16. 이미지 데이터의 Shape

이미지는 일반적으로:

```text
(데이터 개수, 높이, 너비, 채널)
```

형태를 가진다.

예:

```text
x.shape

(60000, 28, 28, 1)
```

이라면:

```text
60000 = 이미지 개수
28    = 높이
28    = 너비
1     = 채널
```

따라서 모델에는:

```python
Input(shape=(28, 28, 1))
```

을 사용한다.

RGB 이미지라면 채널이 3이다.

예:

```text
(50000, 32, 32, 3)
```

모델 입력:

```python
Input(shape=(32, 32, 3))
```

# 18. 데이터 전처리 - MinMaxScaler

이번 시간에는 데이터 전처리 방법 중 하나인 **Min-Max Scaling**을 학습했다.

MinMaxScaler의 기본 공식은 다음과 같다.

$$
x' =
\frac{x-x_{min}}
{x_{max}-x_{min}}
$$

즉:

```text
       원래 값 - 최소값
x' = --------------------
       최대값 - 최소값
```

이다.

---

# 19. MinMaxScaler의 원리

예를 들어 어떤 Feature의:

```text
최소값 = -1
최대값 = 10000
```

이라고 하자.

최소값 `-1`을 넣으면:

$$
\frac{-1-(-1)}{10000-(-1)}
=0
$$

따라서:

```text
-1 → 0
```

이 된다.

최대값 `10000`을 넣으면:

$$
\frac{10000-(-1)}{10000-(-1)}
=1
$$

따라서:

```text
10000 → 1
```

이 된다.

그 사이의 값들도 비율에 따라 `0~1` 사이로 변환된다.

중요한 점은 **Feature별로 각각 최소값과 최대값을 계산하여 Scaling한다는 것**이다.

---

# 20. MinMaxScaler 사용법

```python
from sklearn.preprocessing import MinMaxScaler

scaler = MinMaxScaler()

scaler.fit(x)

x = scaler.transform(x)

print(x)

print(np.min(x), np.max(x))
```

예:

```text
0.0 1.000000000002
```

이론적으로는:

```text
0.0 ~ 1.0
```

범위가 된다.

`1.000000000002`처럼 아주 미세하게 1을 넘어가는 값이 표시될 수 있는 이유는 **컴퓨터의 부동소수점 연산 오차** 때문이다.

즉 실제 의미상으로는 거의:

```text
1.0
```

이라고 보면 된다.

---

# 21. 실제 모델에서는 `x_train`에만 `fit()`해야 한다

위 코드는 MinMaxScaler의 동작을 확인하기 위한 간단한 실습에서는 사용할 수 있다.

하지만 실제 머신러닝 모델에서는:

```python
scaler.fit(x)
```

처럼 전체 데이터의 최소값과 최대값을 미리 확인하면 **Validation/Test 데이터의 정보가 Training 과정에 들어가는 Data Leakage가 발생할 수 있다.**

따라서 먼저 데이터를 나눈다.

```python
x_train, x_test, y_train, y_test = train_test_split(
    x, y,
    test_size=0.2,
    random_state=333
)
```

그 다음:

```python
scaler = MinMaxScaler()

scaler.fit(x_train)
```

Training 데이터의 최소값과 최대값만 학습한다.

그리고 같은 기준으로:

```python
x_train = scaler.transform(x_train)
x_test = scaler.transform(x_test)
```

한다.

더 간단하게:

```python
x_train = scaler.fit_transform(x_train)
x_test = scaler.transform(x_test)
```

라고 사용할 수도 있다.

핵심:

```text
x_train → fit + transform

x_test  → transform만
```

이다.

# 22. Test 데이터는 반드시 0~1 사이인가?

반드시 그렇지는 않다.

MinMaxScaler는 **Training 데이터의 최소값과 최대값**을 기준으로 변환한다.

예를 들어 Training 데이터가:

```text
최소 = 0
최대 = 100
```

이라면:

```text
0   → 0
100 → 1
```

이다.

그런데 Test 데이터에서 처음 보는 값:

```text
120
```

이 등장한다면:

$$
\frac{120-0}{100-0}=1.2
$$

가 된다.

따라서:

```text
x_train → 기본적으로 0~1
x_test  → 0보다 작거나 1보다 클 수도 있음
```

이다.

이는 오류가 아니라 **Training 데이터의 범위를 벗어난 새로운 값이 들어왔기 때문**이다.

# 23. 오늘 내용 핵심 정리

```text
1. y의 클래스 종류와 개수를 np.unique()로 확인할 수 있다.

2. 다중 분류에서는 출력 뉴런을 클래스 개수만큼 만든다.

3. 출력층의 각 값은 클래스별 점수인 logit이다.

4. Softmax는 logit을 합이 1인 확률 분포로 변환한다.

5. Softmax:
      e^각 logit
   ----------------
      e^logit의 합

6. e^z를 사용하면 모든 값을 양수로 만들 수 있다.

7. Softmax 출력의 합은 1이다.

8. argmax는 가장 큰 값이 아니라
   가장 큰 값이 존재하는 인덱스를 반환한다.

9. One-Hot Encoding은 정답 y의 표현 방법이고
   Softmax는 모델 출력의 확률 변환 함수이다.

10. One-Hot 정답:
    categorical_crossentropy

11. 정수 Label 정답:
    sparse_categorical_crossentropy

12. input_shape는 데이터 Shape에서
    맨 앞의 batch 차원을 제외하면 된다.

13. MinMaxScaler:
        x - min
       ---------
       max - min

14. MinMaxScaler는 Feature별 값을
    일정한 범위로 Scaling한다.

15. 실제 모델에서는 scaler를 x_train에만 fit하고,
    x_test에는 transform만 적용한다.
```
