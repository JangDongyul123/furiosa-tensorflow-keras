## 2. 딥러닝 핵심 개념 (Batch)

### 💡 Batch(배치)를 나누어 쓰는 3가지 이유
1. **메모리 부족 방지 (Memory Overflow)**
   * Input Layer(X)가 10만 개, Output Layer(Y)가 10만 개면 연산 과정에서 파라미터가 10만의 제곱이 되어 메모리 한계를 초과함.
2. **과적합(Overfitting) 방지**
   * 데이터를 통째로 한 번에 학습시키면 모델이 해당 데이터에만 너무 익숙해지는 과적합 현상이 발생하기 쉬움.
3. **실질적 훈련 횟수(Iteration) 증가**
   * 데이터를 분할(Batch)해서 훈련시키면 1 Epoch(전체 데이터 1회전) 내에서도 모델이 여러 번 가중치를 업데이트(훈련)하는 효과를 얻음.

## 3. 신경망(Neural Network)의 기초와 역전파

### 가중치(w)와 역전파(Backpropagation)
* 수식 y = wx + b 에서 **w(가중치, 기울기)**를 정교하게 조정해 나가는 과정을 **역전파(Backpropagation)**라고 함.
* 딥러닝 학습이란 결국 **최적의 가중치(w)를 찾아내는 과정**임.
* 예: X=1일 때 Y=1이고, X=2일 때 Y=2임을 모델이 맞출 수 있는 것은 역전파 덕분.

### 편향(b)의 학습
* **질문:** 최적의 편향(b)을 찾는 것도 역전파인가요?
* **답변:** 네, 역전파 과정에서 가중치(w)와 편향(b)이 함께 업데이트(변경)됩니다.

### 신경망의 레이어(Layer) 구조
* **입력층 (Input Layer):** 데이터가 들어오는 층
* **은닉층 (Hidden Layer):** 입력층과 출력층 사이의 수많은 신경망 층
* **출력층 (Output Layer):** 최종 결과값이 나오는 층
> 🙋‍♂️ **사람이 관여하는 영역**은 데이터가 들어가고 정답이 나오는 **Input Layer**와 **Output Layer**뿐입니다.

### 딥러닝 직관적 비유
* **X (입력)**: 고양이가 물고기를 봄
* **Y (출력)**: 고양이가 침을 흘림
* 그 중간(고양이의 뇌 속)에는 수많은 뉴런(신경망)이 복잡하게 얽혀있고, 이 신경망들을 연결하는 수많은 선들이 각각 수식 (y = wx + b)을 가짐.
  * *흐름 예시: 눈 -> 뉴런(Layer 1) -> 뉴런 -> ... -> 뉴런(Layer 4) -> 입(침샘)*

## 4. 학습 팁과 Loss(손실) 함수

* 훈련(Epoch)은 많이 할수록 모델 성능이 좋아질 수 있지만, 너무 과하게 학습하면 오히려 **과적합(Overfitting)**이 발생함.
* **학습 데이터양을 크게 늘리면** 오히려 적은 Epochs(반복 횟수)만으로도 충분히 학습될 수 있음.
* **LOSS = 'MSE'**: 
  * 오차를 제곱하므로 마이너스(-) 값이 나올 수 없음. (상세 수식은 추후 학습 예정)

## 5. 딥러닝의 블랙박스 (Black Box) 특성

> 💬 **"ChatGPT 개발자들도 은닉층(Hidden Layer) 내부가 정확히 어떻게 작동하여 결과를 내는지 100% 알지 못한다. 그저 손실(Loss)을 최소화하도록 설계하여 모델을 잘 만들어낸 것일 뿐이다."**
